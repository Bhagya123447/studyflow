# 📚 **AI-Powered Study Planner & Tracker**

> 💡 *An intelligent study assistant that helps students plan smarter, stay focused, and track progress effectively.*

---

## 🚀 **Overview**

The **AI-Powered Study Planner & Tracker** is a smart web app that helps students manage their learning habits efficiently.  
It uses **AI** to analyze study data, provide insights, and enhance productivity through personalized recommendations.

---

## ✨ **Key Features**

### 🔐 **User Authentication**
- Secure and personalized login system.

---

### 🏠 **Dashboard**
- 👋 Personalized greeting with progress overview.  
- ⏱️ Pomodoro-style **Focus Timer**.  
- ✅ View completed and pending tasks.  
- 🧠 AI-generated insights (4 smart blocks).

---

### 📅 **Calendar**
- 🔥 Heatmap showing your most active study days.  
- 📖 Detailed view of current and past study sessions.

---

### 📝 **Tasks**
- ➕ Add and manage study tasks.  
- 🎯 Filter by difficulty and completion status.  
- 📋 Organized display with progress tracking.

---

### 📊 **Statistics**
- 📆 Weekly bar charts:
  - **Day vs. Time Spent**
  - **Day vs. Focus Score**
  - **Time vs. Subject Studied**

---

### 🤖 **AI Insights**
- 🕒 Detect your **peak focus hours**.  
- ⚡ Analyze energy patterns and suggest breaks.  
- ☕ Recommend optimal rest intervals.  
- 📈 Provide productivity summaries.

---

### ⚙️ **Settings**
- 🎚️ Customize **focus** and **break durations**.  
- 🔄 Toggle **auto-start breaks**.  
- 🔔 Manage **notifications** and **sound effects**.  
- 🧭 Define **daily/weekly study goals**.  
- 🤖 Choose **AI insight frequency** (daily or weekly).  
- 💾 Auto-save for instant updates.

---

## ⚙️ **Installation & Setup**

### 🔧 Prerequisites
- Node.js & npm  
- Python & pip  
- Firebase CLI (optional)

---

### 💻 **Frontend Setup**
```bash
cd frontend
npm install
npm start
````

---

### 🖥️ **Backend Setup**

```bash
cd backend
npm install
node server.js
```

---

### 🤖 **AI Module Setup**

```bash
cd ai-module
python -m venv venv
source venv/bin/activate   # On Windows: .\venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
